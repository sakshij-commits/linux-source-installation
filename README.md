# Installing Software from Source on Linux

This project demonstrates how to download, compile, and install
software from source code on Linux.

## Process

1. Download the source archive
2. Extract the archive
3. Run `./configure`
4. Compile using `make`
5. Install using `make install`
6. Verify the installation

## Commands Used

- `wget`
- `tar`
- `./configure`
- `make`
- `sudo make install`

## Result

The GNU Hello program was successfully compiled and installed
from source.
