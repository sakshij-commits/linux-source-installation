# Installing Software from Source on Linux

This project demonstrates how to download, compile, and install
software from source code on Linux.

## Process

1. Create a Bash script
2. Add the installation commands to the script
3. Change the script permissions to make it executable
4. Execute the script
5. Download the source archive
6. Extract the archive
7. Run `./configure`
8. Compile using `make`
9. Install using `make install`
10. Verify the installationx

## Commands Used

- `vim`
- `chmod`
- `wget`
- `tar`
- `./configure`
- `make`
- `sudo make install`

## Result

The GNU Hello program was successfully compiled and installed
from source.
